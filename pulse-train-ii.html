Pulse Train II

A second board in Pulse Train's palette rather than more of the same units — a companion sine generator, and three effects that weren't there yet: a delay pushed toward infinite freeze instead of an echo, a short feedback delay tuned as a metallic comb resonator, and a digital reverb built from a synthesized impulse response instead of a recorded room. Same universal-node rule as Pulse Train and Signal Chain — every unit is both an input and an output — same minimal/glitch lineage. How this actually works

The same universal-node rule as Pulse Train and Signal Chain. Every unit exposes an in and at least one out, any out can patch into any in, and a footswitch is a real bypass. This board doesn't repeat Pulse Train's units — no second Click, no second Ring — it adds three effects that weren't in the family yet, plus a second Tone (identical design to Pulse Train's: an undistorted sine, hard-clipped only as a feedback-loop safety net, with a second output running at a knob-set frequency ratio instead of a fixed octave).

Freeze is a delay pushed somewhere Signal Chain's Echo never goes: feedback runs up to 98%, not the usual 80-90%, so instead of a decaying repeat you get a loop that barely decays at all — whatever was in the delay line when you turned the knob up keeps cycling almost indefinitely. Comb uses the same feedback-delay idea at a completely different time scale: delay times short enough to be inaudible as separate echoes (down to half a millisecond) reinforce or cancel specific frequencies instead, the classic comb-filtering effect behind physical-modeling and Karplus-Strong-style synthesis — the freq knob sets delay time to 1/freq internally, so it reads as a pitch, not a time.

Space is the site's first use of a ConvolverNode: rather than recording a real room, it synthesizes its own impulse response on the fly — filtered noise shaped by an exponential decay envelope, regenerated whenever the size knob moves — and convolves the input against that. It's a real convolution reverb, just built from math instead of a microphone in a cathedral, which keeps it in the same "cold, precise, digital" register as everything else in this family rather than reaching for lush analog warmth.

Feedback loops are allowed on purpose, same as Pulse Train and Signal Chain: Output's own out can patch back into the board, and the compressor and hard limiter before the speakers exist specifically so that stays loud, not dangerous. Freeze in particular can build up fast in a feedback patch — start low.
