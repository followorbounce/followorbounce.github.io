# followorbounce.github.io — Knowledge Network

Personal index/hub site: essays, interactive experiments, media-server tooling, visual/audio synthesizers, and reference dictionaries, served from GitHub Pages root. **Note:** earlier memory summarized this repo as just "design-divine-future-dictionaries" — it is much larger; the two dictionaries are one corner of a full personal site.

## Structure
- **Architectural rule: every page is a fully self-contained single `.html` file at repo root** (exception: the video-synth family lives in `visual-synths/`). `/assets/` holds `favicon.svg`, shared visual-synth-kit files, and `theme-toggle.js`. Respect this convention; don't introduce shared assets casually.
- **Unified theme toggle** (2026-09-26): `/assets/theme-toggle.js` is loaded (sync, in `<head>`) on every page. It reads `fb-theme` from localStorage (falls back to `prefers-color-scheme`), sets `data-theme` on `:root` before first paint, and injects a Light/Dark button into `header .wrap` (or `#chrome` for the node-based-development field-guide). The index's own toggle in `engine/cubes.js` still exists; `theme-toggle.js` skips injection if `#btn-theme` already exists, so they coexist. Every page must have matching `@media(prefers-color-scheme:dark){:root:not([data-theme="light"]){...}}` and `:root[data-theme="dark"]{...}` CSS blocks. Dark-by-default pages (Pulse Train family, Signal Chain, Heavy Machinery Blueprint) use `[data-theme="light"]` instead to provide a light alternative.
- **Dark-mode helpers for legacy literals** (2026-10-02): essay pages that paint canvases call `themeColor('--token', '#literal')` (defined inline right after the theme-toggle `<script>`; returns the literal in light mode). Hardcoded light CSS colours are written `var(--dk-<hex>, #<hex>)` with `--dk-*` defined only in the two dark blocks. Use the CSS tokens directly in new code instead.
- `index.html` — the Knowledge Network hub/index. **Generated, not hand-edited** (since 2026-09-17): produced by `engine/build_network.py` from `engine/own-pages.json` (this repo's own pages) plus `aerospace/pages.json`, `Maya-Calendar/pages.json`, and `machinery/data/graph.json` (each sibling repo's own source of truth). To add/change an entry for this repo's own pages, edit `engine/own-pages.json`, then re-run `python3 engine/build_network.py` — don't hand-edit the generated `index.html` directly, it'll be overwritten on the next run. The JS fetches, on every page view, the newest post of the **Art tasks** category (slug `art-tasks`) of `designdivinefuture.wordpress.com` from the public WordPress.com REST API (CORS-open) — so it updates itself daily with no rebuild — and renders category / title / summary / terms chips / time limit / first image (letterboxed on a fixed mat, never cropped). A full-width interactive canvas below the Term of the Day cards. 6 modes, in bar order Lines, Grid, Scan, Matrix, Meadow, Mesh. Starting mode (2026-10-16, owner rule): until the visitor clicks a mode, each visit opens a random one different from the last auto-shown (localStorage `fob-gen-auto`); after a click, `fob-gen-mode` is reopened (both try/catch) — same rule as the Instruments tabs. **Grid** (added 2026-09-29, light-installation language): always a black stage with white light regardless of theme, a lattice of squares that cycle through four cross-faded 7 s movements (rotate / breathe / outlined diamonds / travelling bars) driven by a radial wave from the pointer; press-and-hold morphs squares into circles; no strobing. Flowers are SDF sprites in drifts, sized by depth, iridescent (`pal`), open by day / close and glow at night, heads lean toward the sun. A slow pigment field (`pal2`, computed per vertex) sweeps colour through the grass; the sky shader has domain-warped pigment clouds, stars, a sun with bloom and the moon drawn in **today's real phase** (synodic month from 2000-01-06). **Sky clock:** sun on a 24 h arc (rises 06:00 left, noon overhead, sets 18:00 right), moon offset by its phase; default "dream time" starts at the visitor's local time and runs one day per `DREAM_DAY` = 120 s; the mode's option button "Your time" pins it to the real clock (forced under reduced motion). Test hook: `window.__genPreserve=true` before the script makes the GL canvas preserve its buffer and exposes `window.__meadow` / `window.__meadowDraw(t)` for read-back tests (headless screenshots capture WebGL as black). Each mode has a one-line hint overlaid in the frame (`#gen-hint`) and at most one option button (`#gen-opts`: Mic for Lines, Your time for Meadow). Kept deliberately to two interactions per mode. Palette adapts to light/dark theme. Only animates while in viewport (IntersectionObserver). No external dependencies.
