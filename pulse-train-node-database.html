Reference · Pulse Train Architecture

Node Database

Pulse Train — Stage II is a browser instrument, but nothing in it is make-believe DSP. Every node below is documented three ways: the actual technique the JavaScript uses, the math that technique is an implementation of, and a real chip — a real part number, from a real manufacturer, that a hardware version of this same node would reasonably be built from.

Organized the same way the instrument itself now is — Sources, Character, Time, Master — twelve nodes, three views each.

Software technique The math Real hardware equivalent
01 — Sources

Where the signal starts

Tone, Tone II, and Rhythm are the only nodes with nothing patched into their own in by default — everything downstream is shaping something one of these three already produced.

Tone / Tone IIpure sine · fm input
Software

A single OscillatorNode per voice, undistorted sine, hard-clipped only as a feedback-loop safety net. Whatever's patched into in sums directly into the oscillator's own frequency AudioParam — linear FM, not exponential. A second oscillator, locked to the first by the ratio knob, gives each Tone a second output.

Math
f(t) = f_c + k·m(t)
y(t) = A·sin(2π·f(t)·t)

Linear FM: the modulator adds directly to carrier frequency in Hz, not to its exponent — so FM depth is felt the same at 40Hz as at 2000Hz, unlike 1V/oct analog FM.

Real component

TL074Texas Instruments$0.70
quad op-amp integrator core
LM13700Texas Instruments$1.70
exponential converter + sine shaper
LM311Texas Instruments≈$0.50
Schmitt-trigger comparator for the triangle/square core

Rhythmimpulse · edge-triggered
Software

Highpassed noise gated by a near-instant attack / fast decay envelope — a click, not a tone. Fires on its own clock and again on any rising edge detected at its in, the same edge-trigger technique used for Sonar back on Signal Chain.

Math
e(t) = A·rect(t/w)
trigger: x[n] > θ, x[n−1] ≤ θ

A rectangular envelope of width w; the edge detector is a simple rising-edge threshold crossing, exactly what a Schmitt trigger does in hardware.

Real component

TLC555Texas Instruments≈$0.40
monostable timer, fires one fixed-width pulse per trigger
LM311Texas Instruments≈$0.50
edge-detect comparator on the external trigger input

02 — Character

What colors the signal

Crush, Ring, Drive, and Field don't generate anything — each takes a signal and does one specific, well-defined thing to its waveform, spectrum, or stereo position.

Crushbit reduction · gate
Software

A WaveShaper curve pre-computed as a staircase — 1024 samples, each rounded to one of 2^bits flat bands — quantizes amplitude resolution. A second stage, an audio-rate square oscillator driving a GainNode, chops the result on and off.

Math
Q(x,b) = round(x·2^(b−1)) / 2^(b−1)

Bit-depth quantization: b controls how many discrete amplitude levels survive. This is inherently digital math — there's no continuous-voltage circuit that "rounds," only ones that approximate it.

Real component

CD4066BTexas Instruments≈$0.70
bilateral switch for the audio-rate gate stage
the bit-mask itself has no honest discrete-analog equivalent — it runs on a small control MCU's ADC/DAC, the same way it runs on the CPU in the browser.

Ringring modulation
Software

An oscillator's output connects directly into a GainNode's own gain AudioParam — the input signal literally multiplies a second, independent oscillator, true four-quadrant ring modulation rather than a tremolo-style one-sided amplitude wobble.

Math
y(t) = x(t)·cos(2πf_c t)
= ½[X(f−f_c) + X(f+f_c)]

Multiplying two signals shifts the input's spectrum up and down by the carrier frequency — sum and difference sidebands, with neither the original fundamental nor the carrier surviving in the output.

Real component

LM13700Texas Instruments$1.70
cross-coupled OTA pair biased as a 4-quadrant multiplier
AD633Analog Devices$18.35
laser-trimmed multiplier — cleaner, pricier upgrade path

Drivesaturation
Software

Ported from Signal Chain unchanged. A WaveShaper curve computed from tanh, normalized so the curve always reaches ±1 at the input extremes no matter how hard drive is turned up, followed by a lowpass for tone.

Math
y = tanh(k·x) / tanh(k)

tanh is an odd function — its expansion contains only odd-order terms, so saturating a sine adds only odd harmonics (3rd, 5th, 7th…), the same harmonic signature associated with "warm" tube-style overdrive.

Real component

TL074Texas Instruments$0.70
op-amp gain stage with a diode pair across the feedback path — the textbook soft-clip circuit behind most real overdrive pedals, diode forward-conduction standing in for tanh's smooth compression

Fieldstepped stereo panner
Software

A sine LFO runs through a second staircase WaveShaper — the same quantization curve as Crush, just applied to a control signal instead of audio — before driving a StereoPannerNode's pan AudioParam, so the pan position jumps between fixed steps instead of sweeping smoothly.

Math
pan(t) = round(N·LFO(t)) / N

The same quantization function as Crush's Q(x,b), reused on a control-rate signal instead of an audio-rate one — one function, two very different-sounding jobs depending on what it's applied to.

Real component

CD4051BTexas Instruments≈$0.70
8-channel analog mux, stepped between discrete pan taps
SN74HC393Texas Instruments≈$0.60
binary counter clocking the mux — a literal hardware staircase

03 — Time

What happens after the signal arrives

Freeze, Comb, Shimmer, and Space are all, underneath, the same operation — delay a copy of the signal and mix it back in — run at wildly different time scales and feedback amounts.

Freezedelay · pushed toward infinite
Software

A DelayNode with its own output fed back into its input through a gain stage set as high as 98% — not the usual 80–90% an echo tops out at — so a struck signal barely decays, cycling almost indefinitely instead of fading into a handful of discrete repeats.

Math
y[n] = x[n] + β·y[n−D]

A feedback comb / IIR delay. Stable only for |β| < 1 — at β = 0.98 the impulse response decays by roughly 2% per pass, audible as a very slow fade rather than silence.

Real component

V3205 ×2CoolAudio$8.25 ea
4096-stage bucket-brigade delay, cascaded for length
LM13700Texas Instruments$1.70
OTA sets the feedback level the same way feedback.gain does

Combmetallic resonator
Software

The identical feedback-delay structure as Freeze, at a completely different time scale: delay times short enough to be inaudible as separate echoes (down to half a millisecond). The freq knob sets delay time to 1/freq internally, so it reads as a pitch, not a duration.

Math
y[n] = x[n] + β·y[n−D]
H(f) peaks at f = k/D, k ∈ ℤ

Same recurrence as Freeze, but at these delay times the ear stops hearing discrete echoes and starts hearing a comb-shaped frequency response — peaks and nulls spaced at harmonics of 1/D.

Real component

V3207CoolAudio$5.35
1024-stage bucket-brigade delay, 51.2ms max — short enough range for comb-filter time scales without cascading multiple chips

Shimmerchorus
Software

Ported from Signal Chain unchanged. About as plain as a chorus circuit gets: a short (~18ms) DelayNode, with a slow sine LFO wobbling the delayTime AudioParam itself rather than mixing in a second pitch-shifted voice.

Math
y(t) = x(t − τ(t))
τ(t) = τ₀ + d·sin(2πrt)

A time-varying delay is a disguised frequency shift: the instantaneous pitch shift is proportional to dτ/dt, the rate of change of delay time — which is exactly why modulating delay time, not mixing pitched copies, is how real chorus circuits work too.

Real component

V3207CoolAudio$5.35
same BBD family as Comb, clocked by a VCO instead of a fixed oscillator so the LFO modulates clock rate — the classic analog-chorus circuit (Boss CE-1/CE-2 lineage) built from exactly this part family

Spacesynthetic-impulse reverb
Software

A real ConvolverNode, but against a synthesized impulse response rather than a room recording: filtered noise shaped by an exponential decay envelope, regenerated whenever size moves, then convolved against the input.

Math
y[n] = (x * h)[n] = Σ x[k]·h[n−k]
h[n] = noise[n]·(1 − n/N)^p

Direct convolution against an exponentially-decaying noise impulse response — the mathematically "correct" way to simulate a space, at the cost of no closed-form circuit that performs a true convolution.

Real component

FV-1Spin Semiconductor≈$5.50
a complete stereo reverb DSP with its own ADC/DAC on one chip — not literal block convolution, but the closest real, affordable hardware gets to the same perceptual result

04 — Master

Where every signal has to end up

Output isn't one more patchable unit — its compressor and hard-clip stage are always in the signal path, and Gate and Kill live inline inside it rather than as separate nodes, so nothing can route around them.

Gatesquare-wave chop · rave
Software

A sawtooth run through a threshold WaveShaper becomes a variable-duty pulse; scaled to ±0.5 and summed onto the master GainNode's own gain AudioParam (base 1 when off, 0.5 when engaged), it swings the entire mix between silent and full on every cycle.

Math
y(t) = x(t)·g(t)
g(t) ∈ {0,1}, duty = d

Amplitude modulation by a rectangular wave of adjustable duty cycle — mute and unmute, at audio or sub-audio rate, literally rendered as a square wave.

Real component

CD4066BTexas Instruments≈$0.70
bilateral switch chopping the master bus, PWM-driven by the control MCU for variable duty cycle

Killmomentary mute-all
Software

A single GainNode held at 1, ramped to 0 in ~3ms on pointerdown or a held key, and back to 1 on release — momentary, not toggled, the same gesture as a hand on a mixer's mute button.

Math
y(t) = x(t)·[1 − hold(t)]

A binary gate identical in form to Gate's g(t), just driven by a person's hand instead of an oscillator.

Real component

small N-ch MOSFETdiscrete≈$0.50
shunts the master bus to ground while a footswitch is held — about as close to "one transistor" as any function on this board gets

Outputmaster · limiter · monitor
Software

A DynamicsCompressorNode as a limiter, a GainNode ceiling for the volume knob, and a fixed hard-clip WaveShaper as a safety net against feedback-loop overload — always active, not something a footswitch can bypass.

Math
y = clip(x·G), |y| ≤ 0.92

Master gain G followed by a fixed clamp — the same clipping family as Drive's tanh, but hard-edged and non-adjustable, a safety rail rather than a character control.

Real component

LM13700Texas Instruments$1.70
OTA-based master VCA under the volume control voltage
TPS7A4701 / TPS7A3301Texas Instruments≈$4.70
precision low-noise ±12V regulators — clean rails for every OTA and BBD on the board

On the hybrid approach Crush and Gate's bit- and duty-cycle math have no honest discrete-analog circuit — they're sample-accurate operations, so a faithful hardware build runs them on a small control MCU next to the analog signal path, not instead of it. Every other node here has a real, decades-old analog circuit doing the identical job. That split — not "digital vs. analog" as a purity contest, but each technique used where it actually fits — is the same one Pulse Train — Stage II's own code draws, just in JavaScript instead of silicon.
